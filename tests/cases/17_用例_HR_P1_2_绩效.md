# P1-2 绩效 · 测试用例

> 文档编号：`TS-CASE-HR-PERF`
> 所属总纲：[`00_测试总纲.md`](./00_测试总纲.md)
> 模块范围：绩效方案、指标库、考核周期与阶段机、考核表生成、目标下达与审核、自评、上级评分、HR 校准、强制分布预警、结果确认、申诉、归档、等级分布、导出、绩效→薪酬联动
> 任务数：12　用例数：18

---

## 模块信息

| 项 | 内容 |
| --- | --- |
| **对应接口** | `/hr/perf/**`（方案 / 指标 / 周期 / 考核表 / 评分 / 校准 / 申诉 / 分布 / 导出）；`/hr/salary/calc`、`/hr/salary/review`（联动验证） |
| **对应页面** | `/hr/performance`（绩效管理，5 页签）、`/hr/my-performance`（我的绩效） |
| **权限码** | `hr:performance`（列表）、`hr:performance:plan`（方案/指标/周期）、`hr:performance:indicator`（指标库）、`hr:performance:target`（目标审核）、`hr:performance:score`（上级评分）、`hr:performance:calibrate`（校准/申诉处理/归档）、`hr:performance:export`（导出）、`hr:performance:my`（我的绩效） |
| **阶段机** | 1 目标设定 → 2 自评中 → 3 上级评分 → 4 校准 → 5 结果确认 → 6 已归档 |
| **错误码** | 6501 权重合计≠100 / 6502 指标编码重复 / 6503 方案不存在 / 6504 阶段不符 / 6505 目标未锁定 / 6506 考核表不存在 / 6507 非直属上级 / 6508 分数越界 / 6509 校准无理由 / 6510 重复申诉 / 6511 超申诉期 / 6512 已归档只读 / 6513 周期日期重叠 / 6514 方案被引用 / 6516 当期无考核表 / 6517 未填目标 / 6518 未配等级映射 |
| **评分口径** | 总分 = `Σ(得分 × 权重) + 加分 − 扣分`，四舍五入 1 位，封顶 120 / 封底 0；加分合计 ≤10、扣分合计 ≤20；等级按方案区间映射，系数随等级 |
| **依赖模块** | P1-1 薪酬（绩效工资 = 档案绩效基数 × 绩效系数）、P0-1 员工档案（直属上级 / 部门）、P0-2 考勤（考核周期参与人筛选） |

### 本模块执行前置（在 3.2 通用前置之外）

1. 已执行 `oa-system/数据库/hr_p1_perf.sql`（9 张表 + 菜单 263~270 + 授权）。
2. 已执行 `oa-system/数据库/hr_p1_salary_seed.sql`（13 条薪资档案 + 回填 `direct_leader_id`）。
3. 准备三个身份：admin（超管）、员工 `EMP`（TECH_ENGINEER）、其直属上级 `LEADER`（TECH_MANAGER）。`EMP` 与 `LEADER` 的 `entry_date` 需早于考核周期起始日 1 个月以上（否则不参与当期考核）。
4. 已知薪酬核算要求**全员**有生效薪资档案，否则报 6401。
5. 工资条需**复核后**才对员工可见（状态 ≥ 已复核）。
