## 模块信息

| 项 | 内容 |
| --- | --- |
| **对应接口** | `GET /system/login-log/page`、`GET /system/login-log/export`、`DELETE /system/login-log/clean` |
| **对应页面** | `/log/login-log`（页面文件 `views/system/login-log/index.vue`） |
| **权限码** | `system:login-log:query`（分页）、`system:login-log:export`（导出）、`system:login-log:clean`（清理） |
| **数据来源** | 表 `oa_login_log`，**由 M01 登录流程写入，本模块不提供任何新增接口**；测试前须先产生登录记录 |
| **依赖模块** | M01 登录与认证（日志生产者）、M05 菜单管理（权限码来源）、M14 操作日志（本模块的导出/清理动作会被 M14 采集） |

### 本模块执行前置（在 3.2 通用前置之外）

1. `PRE-M13-1`：`oa_login_log` 中已有**历史真实登录记录**（总纲 3.3 明确本表不作基线校验）；若为空，须先按 `PRE-M13-2` 造数。
2. `PRE-M13-2`：造数方式——用合法账号（`D-ADMIN`）与错误密码各调用一次 `POST /auth/login`，成功 1 条 + 失败 ≥ 1 条，且记录 `create_time` 跨度 ≥ 1 天以便验证时间筛选边界。
3. `PRE-M13-3`：已按 7.1 准备 `D-ROLE-EMP`（**不含**任何 `system:login-log:*` 权限码）并绑定一个测试账号，用于权限码隔离用例。
4. `PRE-M13-4`：**接口参数名已确认**：分页接口的页码参数是 **`pageNo`**（非 `pageNum`），每页条数是 `pageSize`；两者在 `LoginLogPageQuery` 中默认值分别为 `1`、`10`。
5. `PRE-M13-5`：分页插件的 **`maxLimit = 1000`**（`MybatisPlusConfig`），即单页最多返回 1000 条，`pageSize > 1000` 会被截断为该上限。
6. `PRE-M13-6`：**清理接口的 `before` 为必填**（`@RequestParam`，默认 `required=true`）且带 `@DateTimeFormat(pattern="yyyy-MM-dd HH:mm:ss")`；参数缺失 / 格式非法由全局异常处理器统一转为 `code=400`（本模块 `TC-LLOG-08` / `TC-LLOG-09` 为**历史缺陷回归点**）。
7. `PRE-M13-7`：导出用 `curl` 落盘到 `F:/tmp/`，**必须带 `--noproxy '*'`**（见总纲 3.4-2）；文件名含时间戳，须用固定输出名覆盖后再校验。

| 字段 | 内容 |
| --- | --- |
| **优先级** | P0 |
| **场景类型** | 正常场景 |
| **测试维度** | 功能, 回归 |
| **关联任务** | TC-LLOG-01 |
| **关联接口** | `GET /system/login-log/page` |

**前置条件**

1. 见 3.2 通用前置条件
2. 已完成 `PRE-M13-1`，`oa_login_log` 记录数 ≥ 11 条（存在成功的与失败的记录）
3. 已用 admin 取得令牌（`perms` 含 `system:login-log:query`）

**测试步骤**

1. 发送 `GET /system/login-log/page`（不传任何参数），记录 `code` 与 `data`
2. 列出 `data.records` 每行的字段名，统计 `data.records` 条数
3. 逐条比对相邻两行的 `createTime`（或 `id`）先后关系
4. 交叉查询库中最新 10 条记录的 `id`，与响应 `records` 的 `id` 序列比对

**预期结果**

1. HTTP 状态码 `200`，`code = 200`，`message = 操作成功`
2. 默认生效 `pageNo = 1`、`pageSize = 10`：`data.pageNo = 1`、`data.pageSize = 10`、`data.records` 条数 = `10`
3. `data.total` 与 `SELECT COUNT(*) FROM oa_login_log` 相等；`data.totalPages = CEIL(total / 10)`
4. 每行含且仅以这些字段回传：`id`、`userId`、`username`、`loginType`、`ipAddress`、`location`、`browser`、`os`、`loginStatus`、`failReason`、`createTime`
5. 记录按 `id` 倒序（等价 `createTime` 倒序）：`records[0].id > records[1].id > …`
6. 响应体**不含** `password` 字段

**数据校验**

```sql
SELECT COUNT(*) AS total_cnt FROM oa_login_log;
-- 预期：与响应 data.total 完全一致

SELECT id, username, login_status, ip_address, create_time
FROM oa_login_log ORDER BY id DESC LIMIT 10;
-- 预期：id 序列与响应 data.records[].id 逐项一致
```

**数据校验**

```sql

-- 预期：与 pageSize=0 时的 data.total 一致（count 查询仍执行）
```
