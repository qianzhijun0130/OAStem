# 角色与权限定义

系统采用RBAC（基于角色的访问控制）权限模型，通过「用户 - 角色 - 菜单 - 按钮」四级关联实现权限控制。

## 标准角色划分

| 角色名称 | 权限说明 | 典型使用人员 |
| --- | --- | --- |
| 超级管理员 | 拥有系统全部功能权限，负责系统配置、角色分配、数据维护 | 系统管理员、IT 负责人 |
| 部门管理员 | 拥有本部门人员管理、本部门审批查看权限，无系统级配置权限 | 部门主管、部门经理 |
| 普通员工 | 发起审批、查看公告、管理个人信息，仅可操作本人相关数据 | 企业普通员工 |
| HR 专员 | 拥有员工信息管理、人事类审批归档、组织架构查看权限 | 人力资源岗 |
| 财务专员 | 拥有报销、采购类审批财务节点权限，可查看财务相关审批数据 | 财务岗 |

## 权限粒度要求

- **菜单级权限：**不同角色登录后，左侧侧边栏展示对应权限范围内的菜单
- **页面级权限**：无权限访问页面时，自动拦截并跳转至无权限提示页
- **按钮级权限**：页面内新增、编辑、删除、审批等操作按钮，根据角色权限动态显示 / 隐藏

# 核心业务功能需求

## 组织架构管理

1. 以树形结构展示企业全部部门层级，支持展开 / 折叠
2. 支持新增、编辑、删除部门，设置部门名称、部门编码、上级部门、排序
3. 支持部门名称模糊搜索，快速定位目标部门
4. 删除部门时校验：部门下存在员工或下级部门时，禁止删除并给出提示

## 员工用户管理

1. 员工列表展示：姓名、工号、部门、岗位、角色、账号状态、入职时间
2. 支持多条件筛选：部门、角色、账号状态、姓名 / 工号关键词搜索
3. 支持分页查询、批量导出员工信息
4. 新增员工：填写基础信息、分配部门、分配角色、设置初始密码
5. 员工信息编辑、账号启用 / 禁用、重置密码
6. 员工头像上传与预览

## 角色权限管理

1. 角色列表展示：角色名称、角色编码、角色描述、创建时间
2. 新增、编辑、删除角色
3. **权限分配**：以树形结构展示系统全部菜单与按钮权限，支持勾选配置角色权限
4. 权限变更后，对应用户登录时自动更新权限，无需重启系统

## 审批工作流管理

### 支持的审批业务类型

系统内置 6 类企业高频审批场景，全部基于通用审批引擎配置实现：

1. **请假申请**：事假、病假、年假、调休，填写起止时间、请假原因
2. **加班申请**：工作日加班、周末加班、节假日加班，填写加班时长、加班事由
3. **出差申请**：填写出差地点、起止时间、出差目的、预算金额
4. **报销申请**：支持多明细项，填写费用类型、金额、票据说明，自动汇总总金额
5. **采购申请**：填写采购物品清单、数量、预估金额、采购原因
6. **人事申请**：转正申请、离职申请，填写生效时间、说明

### 核心功能点

1. **发起申请**：选择审批类型，动态渲染对应表单，填写后提交或保存为草稿
2. **我的发起**：查看本人提交的所有申请，展示审批状态、提交时间，支持查看详情、撤销（仅审批中可撤销）
3. **我的待办**：展示当前用户需要处理的所有审批事项，支持同意、驳回操作，填写审批意见
4. **我的已办**：展示当前用户已处理完成的审批记录
5. **审批详情**：展示申请单完整表单数据 + 审批历史时间轴，时间轴包含节点名称、审批人、操作结果、审批意见、操作时间
6. **驳回重提**：申请被驳回后，发起人可修改表单内容后重新提交，重新走审批流程

### 审批流转规则

1. 审批通过自动流转至下一节点，全部节点通过则流程终审通过
2. 任意节点驳回，流程直接终止，状态标记为「已驳回」
3. 支持条件分支：例如报销金额＞5000 元时，自动增加财务经理审批节点
4. 审批人暂未处理时，支持转办给其他人员处理

## 公告通知管理

1. 管理员发布公告：填写标题、内容、置顶状态、发布范围（全公司 / 指定部门）
2. 公告列表展示：标题、发布人、发布时间、置顶标记
3. 员工端查看公告详情，未读公告标红提示
4. 支持公告编辑、删除、置顶 / 取消置顶

## 工作台首页

1. **数据概览卡片**：员工总数、部门总数、我的待办数量、我的发起数量
2. **统计图表**：月度审批数量趋势图、审批类型占比图
3. **快捷入口**：发起请假、发起报销、查看待办等高频功能快捷按钮
4. **最新公告**：展示最近 3 条置顶 / 最新公告

## 个人中心

1. 查看个人基础信息：姓名、工号、部门、岗位、入职时间
2. 编辑个人资料、更换头像
3. 修改登录密码，需校验原密码

## 系统管理

1. 登录日志：查看用户登录记录、登录时间、登录 IP
2. 操作日志：记录关键操作（新增、删除、审批）的操作人、时间、内容
3. 系统字典：管理审批类型、部门类型等系统枚举值

# 通用审批引擎设计要求

## 流程模板配置

每类审批对应一个流程模板，模板包含：

- 基础信息：模板 ID、流程名称、流程编码
- 表单字段配置：字段名称、字段类型、是否必填、选项值
- 审批节点配置：节点顺序、节点名称、审批人规则

## 审批人规则

支持三种审批人指派方式：

1. **指定人员**：固定某一个具体用户作为审批人
2. **指定角色**：拥有某角色的所有用户均可处理该节点
3. **部门主管**：自动匹配发起人的直属部门主管

## 流程状态机

统一定义流程状态，禁止非法状态跳转：

| 状态 | 说明 | 允许的操作 |
| --- | --- | --- |
| 草稿 | 未提交的申请 | 提交、编辑、删除 |
| 审批中 | 已提交，正在流转 | 审批通过、审批驳回、撤销 |
| 已通过 | 全部节点审批完成 | 查看详情 |
| 已驳回 | 被任意节点驳回 | 查看详情、重新提交 |
| 已撤销 | 发起人主动撤销 | 查看详情 |

## 条件分支

支持基于表单字段值的条件分支，例如：

- 报销金额 ≤ 1000 元：部门主管审批 → 流程结束
- 报销金额 ＞ 1000 元：部门主管审批 → 财务审批 → 流程结束

# 非功能需求

### 性能需求

- 页面加载响应时间 ≤ 2 秒
- 列表查询响应时间 ≤ 1 秒
- 审批操作提交响应时间 ≤ 1 秒
- 支持 100 人同时在线使用无明显卡顿

### 安全需求

1. 所有接口需身份鉴权，携带有效 Token 才可访问
2. 密码加密存储，不可明文存储
3. 越权访问拦截：禁止用户访问无权限的页面与数据
4. 关键操作留痕，所有审批、删除操作记录操作日志

### 兼容性需求

- 前端兼容 Chrome、Edge、Firefox 主流浏览器最新两个大版本
- 适配 1920*1080、1366*768 等主流桌面分辨率
- 响应式布局，保证不同尺寸屏幕下布局正常

### 可扩展性需求

- 新增审批类型无需修改核心代码，仅需配置流程模板
- 前后端分离架构，支持前端、后端独立迭代部署
- 模块化设计，各业务模块低耦合
