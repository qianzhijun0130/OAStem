# OA 企业办公管理系统数据库建表脚本

# 使用说明

1. 先执行数据库创建语句
2. 按模块顺序执行建表脚本（建议先执行组织架构、权限模块，再执行业务模块）
3. 适用环境：MySQL 8.0+ / InnoDB 引擎 /utf8mb4 字符集
4. 一键执行脚本：[oa_system_init.sql](./oa_system_init.sql)（含建库语句 + 全部 25 张表，可重复执行）

> 执行记录：2026-09-28 已在本机 MySQL 8.0.46（127.0.0.1:3306）执行完毕，数据库 `oa_system` 及全部 25 张表均已创建（InnoDB / utf8mb4_unicode_ci）。

```sql
-- 创建数据库
CREATE DATABASE IF NOT EXISTS oa_system DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE oa_system;
```
